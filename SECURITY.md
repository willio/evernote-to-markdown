# Security policy

## Supported versions

The latest version on the default branch is the supported version.

## Reporting a vulnerability

Please do not include real ENEX exports, credentials, or private attachments in
a public issue. If the GitHub repository has private vulnerability reporting
enabled, use **Security → Report a vulnerability**. Otherwise, contact the
repository maintainer privately through GitHub before disclosing the issue.

Include the affected version, a minimal reproduction that contains no private
data, impact, and any suggested mitigation. The converter is intended to run
offline; reports involving unexpected network access are especially useful.
